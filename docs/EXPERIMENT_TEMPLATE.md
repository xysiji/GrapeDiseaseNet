# Experiment And Thesis Material Template

## Suggested Result Items

- dataset source and class distribution
- training setting summary
- best model file name
- validation and test metrics
- sample prediction screenshots
- interface function screenshots
- error cases and analysis

## Suggested Table Fields

### Dataset Table

- dataset name
- task type
- image count
- class count
- split rule

### Training Table

- model
- epochs
- batch size
- image size
- device
- data augmentation summary

### Result Table

- precision
- recall
- mAP@0.5
- mAP@0.5:0.95
- notes

## Suggested Figure Items

- train/val loss curves
- precision-recall trend
- confusion matrix or per-class statistics
- interface screenshot
- prediction case examples
